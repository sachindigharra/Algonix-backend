1. High-Level Functionality
   Core Purpose**: Central backend for "AlgoNix / DSA Tracker" — a scalable Spring Boot service that aggregates and stores users' coding activity, problem tracking, contest history, and coding-platform profiles so users can monitor progress, revisions, and contest performance.
   * Audience**: Students and software engineers preparing for coding interviews and competitive programming; coaches and study groups.

## 2. Completed Features (Use for Context)
* **User Management**: Registration, login (BCrypt), profile management, role-ready design — main files: /src/main/java/.../controller/UserController.java, /service/, /repository/ and entity packages.
* **Coding Platform Profiles**: Store/link LeetCode/Codeforces/CodeChef/GitHub profiles; keep ratings, max ratings, streaks — main files: platform profile entity, service, repository.
* **Problem Tracking**: Track solved/attempted/todo/revisit, notes, tags, difficulty, sheets association — main files: problems package (controller/service/repository/DTOs).
* **Contest Management**: Store contest participation, ranks, rating deltas across platforms — contest packages.
* **Revision Scheduling**: Problem revision records and scheduling logic.
* **API Docs**: Swagger/OpenAPI configuration for interactive API docs.

## 3. In-Progress & Planned Features (Where bugs/tasks will happen)
* **Current Sprint**: JWT Authentication (access + refresh tokens), stateless security and token refresh endpoints — work located under /src/main/java/.../security/ and auth controller/service.
* **Near-term Planned**: Email verification, password reset flows, dashboard analytics endpoints, better pagination and filtering for big datasets.
* **Long-term Planned**: Leaderboards, AI-powered revision recommendations, contest reminders, deployment automation (Docker, Kubernetes, AWS).

## 4. Technical Stack & Architecture
* **Backend**: Java 21, Spring Boot, Spring Security, Spring Data JPA, Hibernate
* **Database**: PostgreSQL
* **Documentation**: Swagger / OpenAPI
* **Utilities**: Lombok, SLF4J, Bean Validation
* **Architecture**: Controller → Service → Repository → PostgreSQL. Additional layers: DTOs, Mappers, Exception Handling, Logging, Security config.

## 5. Developer Notes (How to run locally)
* Build & run: mvn clean package && mvn spring-boot:run
* Required env vars: SPRING_DATASOURCE_URL, SPRING_DATASOURCE_USERNAME, SPRING_DATASOURCE_PASSWORD, JWT_SECRET (for current sprint)
* Tests: mvn test
* API docs: /swagger-ui.html (when running)

## 6. Where to Look
* Controllers: /src/main/java/**/controller/
* Services: /src/main/java/**/service/
* Repositories & Entities: /src/main/java/**/repository/ and /entity/
* Security & Auth: /src/main/java/**/security/
* Configuration & resources: /src/main/resources/
